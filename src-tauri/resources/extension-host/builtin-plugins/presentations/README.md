# Presentations

Plugin officiel qui crée et modifie des présentations PowerPoint éditables.

## Effet sur le modèle

### Coût

Les schémas des outils Presentations occupent une partie du contexte lorsqu’ils sont chargés.

### Cache

Le plugin ne modifie pas le cache du modèle. Les présentations restent dans l’espace de travail.

### Surface visible

Le modèle voit les outils de création et de modification PPTX ainsi que leurs résultats bornés.
