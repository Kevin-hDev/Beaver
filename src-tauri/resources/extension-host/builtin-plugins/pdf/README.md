# PDF

Plugin officiel qui lit, crée, fusionne et vérifie des fichiers PDF.

## Effet sur le modèle

### Coût

Les schémas des outils PDF occupent une partie du contexte lorsqu’ils sont chargés.

### Cache

Le plugin ne modifie pas le cache du modèle. Les aperçus et fichiers restent dans l’espace de travail.

### Surface visible

Le modèle voit les outils PDF et leurs résultats textuels bornés, jamais les données internes du moteur.
