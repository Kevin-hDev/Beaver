# Documents

Plugin officiel qui crée et modifie des documents Word éditables.

## Effet sur le modèle

### Coût

Les schémas des outils Documents occupent une partie du contexte lorsqu’ils sont chargés.

### Cache

Le plugin ne modifie pas le cache du modèle. Les fichiers produits restent dans l’espace de travail.

### Surface visible

Le modèle voit les outils de création et de modification DOCX ainsi que leurs résultats bornés.
