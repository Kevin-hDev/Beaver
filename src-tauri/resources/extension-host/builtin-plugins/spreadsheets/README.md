# Spreadsheets

Plugin officiel qui crée, inspecte et modifie des classeurs Excel.

## Effet sur le modèle

### Coût

Les schémas des outils Spreadsheets occupent une partie du contexte lorsqu’ils sont chargés.

### Cache

Le plugin ne modifie pas le cache du modèle. Les classeurs restent dans l’espace de travail.

### Surface visible

Le modèle voit les outils de classeur et des aperçus structurés bornés des feuilles demandées.
