# Question Angles

Draw from one relevant section. Do not ask every question.

## Problem and outcome

- What changes when this works, and for whom?
- What current alternative does the user replace?
- What observable result makes the idea worthwhile?

## Actors and boundaries

- Who starts the behavior and who is affected?
- Where does this responsibility end?
- What is the smallest version that still delivers the intended value?

## Constraints and dependencies

- What must already exist?
- Which limits on time, cost, platform, data, or access can change the outcome?
- Which external actor or system can block the result?

## Success and failure

- What can a user observe when the idea succeeds?
- Which failure would make the result unacceptable?
- What should happen when required input or a dependency is missing?
