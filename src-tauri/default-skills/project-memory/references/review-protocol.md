# Independent Review Protocol

Review one memory file without seeing prior findings.

1. Read the file, its cited repository evidence, the destination map, and the memory rules.
2. Flag each issue with an exact file location, decisive evidence, and a safe disposition:
   - unsupported or stale claim;
   - nonexistent path, command, or file;
   - rationale unsupported by code, history, or project documentation;
   - omitted durable decision, convention, boundary, or gotcha shown by evidence;
   - fact assigned to the wrong canonical destination;
   - duplicate fact, secret, placeholder, guidance comment, or other rule breach.
3. Return findings without editing the file.
4. Apply a finding later only when it cannot delete or rewrite unapproved pre-existing text.
5. Run a new independent pass after any correction.

When independent parallel reviewers are unavailable, clear the previous file's draft and findings from the working context before each pass and disclose that substitution in the final report.
