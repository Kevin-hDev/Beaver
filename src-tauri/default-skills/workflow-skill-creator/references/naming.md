# Naming

You choose names that improve triggering and remain stable on disk.

- You use lowercase ASCII letters, digits, and single hyphens in a kebab-case name no longer than 64 characters.
- You make the folder name and frontmatter `name` identical.
- You prefer a direct activity name for a workflow and a singular product or service name for a tool-specific capability.
- You avoid vague names such as `helper`, redundant prefixes such as `skill-`, and names that imply capabilities the workflow does not own.
- You compare the proposed description, positive cases, and negative cases with neighboring skills.
- You keep separate names when two skills share a domain but differ in trigger, method, depth, or output.
- You merge or rename only when the actual triggers, method, and output are equivalent.
