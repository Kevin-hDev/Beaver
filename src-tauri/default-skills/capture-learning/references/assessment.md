# Assessment and Reconciliation

## Score

Score each candidate from 0 to 10 using durability, reuse, project fit, and forgetting risk.

- `0–3`: skip unless the user insists and a safe narrow destination exists.
- `4–5`: keep only in a narrow destination with a clear owner.
- `6–7`: recommend capture.
- `8–10`: strongly recommend capture unless existing content already covers it.

Explain the score from evidence. Do not add the four factors mechanically or imply statistical precision.

## Reconcile

- `new`: no equivalent project content exists.
- `covered`: current content already conveys the lesson accurately; make no write.
- `updates`: refine an existing entry without reversing its decision.
- `supersedes`: replace a prior decision or rule with explicit authority and links.

Never infer supersession from silence, deletion, age, or contradiction alone. Require user confirmation or an authoritative project source.
