# Independent Review Contract

Review every prepared direct write or handoff in a fresh pass before applying it.

## Checks

- Compare the source evidence with the approved lesson.
- Confirm the score, destination, reconciliation, scope, and requested effect match the approved packet.
- Confirm no duplicate, contradiction, unsupported rule, secret, personal data, or unrelated cleanup entered the result.
- Confirm an update preserves unrelated content.
- Confirm ADR supersession points both ways.
- Confirm a rule or skill handoff names an actually available specialized generator and carries the complete packet.
- Confirm memory and ADR delivery includes the approved synchronization plan.

## Verdicts

- `pass`: every check succeeds and delivery may proceed.
- `changes-required`: a correctable rendering or completeness defect remains.
- `blocked`: evidence, approval, convention, safety, or delivery capability is insufficient.

Correct a mechanical defect and review again. Return for explicit approval when a correction changes meaning, destination, reconciliation, scope, or supersession.
