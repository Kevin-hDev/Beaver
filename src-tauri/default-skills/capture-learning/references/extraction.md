# Durable Extraction

## Keep

- A project decision with its tradeoff or consequence.
- A recurring convention or enforceable project behavior.
- A pitfall, failed path, or costly pivot worth preventing.
- A reusable workflow worth documenting or automating.
- Missing project context whose absence caused confusion, contradiction, or rework.
- A review finding that generalizes beyond the reviewed change.

## Drop

- Personal or stylistic preference without project authority.
- Temporary state, current progress, or a one-time reminder.
- Routine implementation detail already clear from maintained code.
- A one-off fact with no plausible reuse.
- Unsupported inference or a proposed rule not accepted by the project.
- Content whose only useful home is the source artifact itself.

## Candidate fields

- Source kind and stable label.
- Short sanitized evidence.
- One precise learning.
- Durability and reuse reason.
- Project scope and affected consumers.
- Stable duplicate key from scope plus normalized lesson.
