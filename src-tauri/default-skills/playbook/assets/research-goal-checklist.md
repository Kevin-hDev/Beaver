# Refine the research goal

You clear this checklist with the user before scouting when the request does not already answer every material item.

- [ ] **Outcome:** You state one precise observable result.
- [ ] **Audience and level:** You identify who will run the playbook and their expected experience.
- [ ] **Scope:** You state what is included and explicitly excluded.
- [ ] **Actionability:** You require concrete actions with observable results, not theory alone.
- [ ] **Grouping:** You decide whether difficulty levels or another project convention helps.
- [ ] **Counter-intuitive wins:** You leave room for evidence-backed options beyond the obvious default.
- [ ] **Freshness:** You define how current time-sensitive evidence must be.
