# 05 - Synthesize

Combine the bounded evidence into one compact result that the user can verify.

## Input

- Accept verified facts, relationships, representative evidence, recorded gaps, and every requested survey, drill, or trace result.

## Output

- Return one concise overview containing every requested map, level, or flow, with evidence links, available depth, and explicit limits.

## Process

1. **Lead with the answer.** State what is present and how each requested behavior flows in one to three sentences.
2. **Choose the shape.** Use a short list for a small map, a table for repeated mappings, and a diagram only when relationships require it.
3. **Attach evidence.** Cite the most direct catalog item, file, and line for every important claim.
4. **Separate certainty.** Keep verified facts, labeled inferences, unavailable surfaces, and unresolved gaps distinct.
5. **Stay descriptive.** Omit quality judgments, fixes, plans, generalized routing, and unrelated facts.
6. **Preserve navigation.** Name only the immediate child levels that the user can select for a later drill.

## Stop conditions

- Never hide an evidence gap behind a confident label.
- Never expose secrets, raw configuration, personal data, or unnecessary internal errors.
- Never report an area as absent when the bounded scan did not inspect it.

## Test

- Confirm that each consequential claim has evidence or an explicit inference label.
- Confirm that the result contains no code change, audit finding, prescription, or executed target capability.
