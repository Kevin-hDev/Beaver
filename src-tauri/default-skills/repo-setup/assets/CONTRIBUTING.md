# Contributing to {{PROJECT_NAME}}

## Setup

Follow the project's installation and development instructions.

## Workflow

1. Create a focused branch from the documented base branch.
2. Keep each change limited to one coherent concern.
3. Add or update tests when behavior changes.
4. Run the project-required checks before opening a review request.

## Conventions

- Follow the repository's commit, branch, review, and release conventions.
- Keep generated files, secrets, credentials, and local configuration out of commits unless project rules explicitly require a safe generated artifact.
- Preserve unrelated work and keep the working tree understandable for the next contributor.
