# Mermaid Conventions

Use these rules for the diagnostic action-path diagram.

- Add a short title and one direction declaration.
- Declare descriptive alphanumeric node identifiers before links.
- Put readable labels in quoted brackets when they contain punctuation.
- Show real components, functions, state transitions, or boundaries from inspected evidence.
- Keep causal links at the bottom and label conditions when they matter.
- Use groups only when they clarify ownership or system boundaries.
- Do not create standalone, empty, decorative, or hypothetical nodes.
- Keep the diagram focused on the path that can produce the reported symptom.
