# External Office fixtures

These fixtures are deliberately not created by Beaver's Office plugins.
They reproduce interoperability cases found by review.

- `external-large-preview.xlsx`: generated with XlsxWriter.
- `external-large-text.pdf`: generated with ReportLab.
- `external-fragmented-runs.pptx`: generated with python-pptx and a placeholder
  split across four styled PowerPoint runs.
- `external-unicode-samples.txt`: generated by Python as UTF-8 input for PDF
  creation across the supported scripts.

Regenerate them from the repository root with:

```bash
uv run --with xlsxwriter --with python-pptx --with reportlab \
  python3 scripts/extensions/fixtures/generate_external_fixtures.py
```
