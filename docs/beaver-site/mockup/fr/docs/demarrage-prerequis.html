Est-ce que ça tourne sur ta machine

Beaver est distribué pour une seule architecture par système : pas de build macOS Intel, pas de build Linux ARM, pas de build Windows ARM. Cette page dit ce qui est pris en charge, ce qu'il faut comme matériel, et ce que demande le premier lancement.

macOS

Beaver fonctionne sur les Mac à puce Apple Silicon (M1 et suivantes) uniquement. Le script d'installation n'accepte que Darwin:arm64 et Darwin:aarch64 ; il n'existe pas d'asset x86_64.

Aucune dépendance n'est à installer : curl et hdiutil sont fournis par le système. L'application n'est pas signée, et macOS Gatekeeper peut la bloquer si le .dmg est téléchargé par un navigateur — c'est la raison d'être du script d'installation, qui passe par curl et évite la mise en quarantaine.

Mac Intel Beaver est distribué uniquement pour les Mac à puce Apple Silicon (M1 et suivantes). Les Mac à processeur Intel ne sont pas pris en charge, et le script d'installation s'arrête avec « Système non pris en charge ».

Windows

x64 uniquement, pas de build ARM. La distribution se fait par un installeur NSIS.

Une réserve à connaître : l'installeur ne prend pas explicitement en charge WebView2 et le runtime Visual C++. S'ils manquent sur une machine vierge, l'application peut ne pas démarrer.

Au premier lancement, si la protection anti-rançongiciel de Windows Defender (« Accès contrôlé aux dossiers ») est active, ollama.exe peut être bloqué quand il écrit les modèles dans ~/.ollama/models/. Une notification Windows apparaît : il faut cliquer « Autoriser ». La demande ne se répète pas ensuite.

Linux

x64 uniquement, au format .deb, pour Debian et Ubuntu. Le paquet est construit sur Ubuntu 22.04, ce qui garantit la compatibilité avec 22.04, 24.04 et 25.04 : la bibliothèque C standard étant rétro-compatible vers le haut, construire sur la plus ancienne cible couvre les suivantes.

Le script d'installation n'utilise que apt-get : les distributions hors famille Debian ne sont pas prises en charge. Deux dépendances sont installées automatiquement, libwebkit2gtk-4.1-0 — le moteur de rendu web de Tauri 2 — et libgtk-3-0, la boîte à outils graphique.

Un problème d'affichage est connu et non résolu : la fenêtre peut s'afficher avec un fond transparent au lieu d'être opaque. La cause n'est pas identifiée ; le compositeur (Wayland contre X11) ou le thème GTK sont des pistes évoquées.

Beaver 1.2.3 est la dernière version qui apporte de nouvelles fonctionnalités à Linux ; ensuite la version Linux passe en maintenance seule, et tout ce qui fonctionne aujourd'hui continue de fonctionner — la décision est expliquée dans Installation Linux.

Linux et navigateur intégré Le navigateur intégré n'est pas disponible sur Linux. Toutes les autres fonctionnalités le sont. Si ce point compte pour toi, il vaut mieux le savoir avant d'installer.

Matériel recommandé

Avec des modèles distants uniquement — clé API ou compte web — n'importe quelle machine récente convient : l'application ne fait que de l'affichage et du réseau.

Avec des modèles locaux, c'est la mémoire vidéo qui décide. Un modèle qui n'y tient pas bascule sur le processeur et devient très lent. Les correspondances entre taille de modèle et machine sont dans Matériel et VRAM.

Deux nuances sur les GPU AMD. Sous Linux, la détection fonctionne et l'archive ROCm est bien téléchargée, mais le résultat n'a pas été validé sur une machine réellement équipée. Sous Windows, Vulkan fonctionne, mais Ollama s'appuie sur une version datée de llama.cpp, avec une perte de performance importante : ne compte pas sur cette combinaison pour une performance maximale.

Réseau

Une connexion est nécessaire si tu choisis d'installer Ollama au premier lancement : le moteur pèse plusieurs centaines de mégaoctets. Le dépôt GitHub doit alors être joignable, car la recherche de mises à jour et le téléchargement d'Ollama passent par l'API GitHub Releases. Cette étape se passe, et se rattrape plus tard depuis Réglages › Ollama.

Ensuite, l'application fonctionne hors ligne avec un modèle local déjà téléchargé. Les modèles distants et la recherche web exigent évidemment une connexion.

Premier lancement Si tu choisis d'installer Ollama, le téléchargement vient de GitHub : prévois une connexion et quelques centaines de mégaoctets. Ensuite, l'application fonctionne hors ligne avec un modèle local. Si tu passes l'étape, Beaver démarre sans rien télécharger.

Ensuite

La procédure de ton système : macOS, Linux ou Windows. Ce qui se passe après est décrit dans Premier lancement, et les échecs sont traités dans Dépannage installation.
