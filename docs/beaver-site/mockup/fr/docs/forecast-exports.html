Sortir une prévision de Beaver

Sept formats, du tableau à plat au rapport imprimable. Cette page dit ce que chacun contient réellement, où le fichier atterrit et comment il est nommé — parce que d'un format à l'autre, ce n'est pas la même chose qui sort.

À retenir Les sept sorties existent et fonctionnent : CSV, Excel, PNG, SVG, JSON, PDF et copie dans le presse-papiers. Le fichier part dans ton dossier de téléchargements, nommé d'après l'analyse.

Les sept sorties, et où les trouver

Le bouton porte le libellé Export et ouvre un menu de sept entrées.

Le bouton apparaît à deux endroits, et c'est le même : dans le pied du panneau Forecast dès qu'une analyse est ouverte, et dans la barre d'outils de la section Rapport de la fenêtre Espace Forecast.

Trois messages possibles après l'action : « Export enregistré », un fichier a été écrit ; « Export copié », le texte est dans le presse-papiers ; « Export impossible », l'export a échoué, sans autre précision.

Où va le fichier, et comment il s'appelle

La destination est le dossier de téléchargements du système. Quand celui-ci est introuvable, Beaver retombe sur un dossier d'exports créé au besoin sous son propre dossier de données.

Le nom du fichier suit toujours la même forme : le nom de l'analyse nettoyé, un tiret, les huit premiers caractères de son identifiant, puis l'extension. Le nettoyage est strict : seuls les lettres et chiffres non accentués sont conservés, en minuscules ; les espaces, tirets et traits soulignés deviennent des tirets ; tout le reste est supprimé, accents compris ; les tirets consécutifs sont réduits à un seul ; le résultat est coupé à 64 caractères. S'il ne reste rien, le nom devient forecast.

Les huit caractères d'identifiant à la fin évitent que deux analyses portant le même nom s'écrasent l'une l'autre. Une analyse ne peut être exportée que depuis la conversation à laquelle elle appartient : l'autorisation est vérifiée avant toute lecture.

Attention Les accents disparaissent du nom de fichier. « Prévision CA — été 2026 » devient prvision-ca-t-2026 : les accents ne sont pas translittérés, ils sont supprimés. Le contenu du fichier, lui, garde les accents.

Ce qu'il y a dans tout export

Quel que soit le format, l'export part du même assemblage : l'analyse complète et ses notes. Les notes ne sont donc jamais laissées de côté, même dans un export de données brutes.

Les en-têtes de fourchette s'adaptent au niveau de confiance demandé. Ils ne sont pas figés : ils sont calculés à partir du niveau retenu.

Deux exemples d'en-têtes de fourchette

Une valeur non finie sort vide, jamais sous forme de texte parasite.

CSV — le tableau à plat

Un seul tableau, dix colonnes, qui empile tout ce que l'analyse contient : section, name, date, series_id, value, les trois en-têtes de fourchette, puis text et source.

Ce que dit la colonne section
ValeurCe que la ligne porte
historyUn point de l'historique fourni
predictionUn point prévu, avec sa fourchette
scenarioUn point d'un scénario, dont le nom est dans name
annotationUne annotation posée sur le graphique
noteUne note attachée à l'analyse
residual_anomalyUn écart notable relevé après le calcul
variable_importanceLe poids d'une variable explicative
driftUn constat de dérive sur une série
ensemble_memberUn modèle et son poids dans un ensemble
Sécurité Tes exports ne peuvent pas exécuter de formule. Une cellule de texte commençant par =, +, - ou @ est neutralisée avant écriture, dans le CSV comme dans le classeur Excel : un tableur qui ouvre le fichier affiche le texte au lieu de l'exécuter. C'est pourquoi certaines cellules apparaissent avec une apostrophe en tête.

Excel — un classeur, huit feuilles

Les feuilles du classeur, dans l'ordre de création
FeuilleContenuToujours présente
MetadataIdentifiant, nom, modèle, fournisseur, cible, fréquence, date de création, horizonOui
HistoriqueLes points fournis : date, série, valeurOui

ScenariosLes points de chaque scénario, précédés de son nomOui — vide s'il n'y en a pas

Chaque feuille reçoit une ligne d'en-tête figée, un filtre automatique et un ajustement de largeur des colonnes plafonné à 52 caractères. Le classeur est lui aussi protégé de l'injection de formule : un titre de note écrit comme une formule reste du texte.

À retenir Le classeur emporte tes données de départ. Sa dernière feuille, Input data, contient le fichier d'origine ligne par ligne. C'est le seul export qui permet de refaire tout le travail à partir d'un fichier unique.

JSON — tout, sans perte

Le fichier contient trois clés à la racine : analysis, l'analyse entière telle qu'elle est enregistrée ; notes, les notes attachées ; quantile_labels, les trois en-têtes de fourchette correspondant au niveau de confiance.

Le fichier est mis en forme lisiblement, pas compacté. C'est le seul format qui ne perd rien : tous les autres sélectionnent, arrondissent ou mettent en page. C'est le format à conseiller pour alimenter un autre programme.

PNG et SVG — l'image du graphique

Les deux sortent le même dessin : le SVG est écrit tel quel, le PNG en est le rendu.

Les caractéristiques de l'image exportée
CaractéristiqueValeur
Dimensions1 400 × 760 pixels
FondSombre, quel que soit ton thème
TitreLe nom de l'analyse
Sous-titreModèle, colonne cible, horizon, nombre de points
CourbesHistorique en gris clair, prévision en orange avec un point par échéance, scénarios en bleu pointillé
Zone de confianceUne bande orange transparente autour de la prévision
RepèresAxe horizontal daté et grille horizontale avec valeurs
LégendeTrois entrées : Historique, Prevision, Confiance

La légende est écrite en français dans l'image, sans passer par les traductions — et le mot « Prevision » y apparaît sans accent.

Une particularité à connaître : l'axe des valeurs ajoute un symbole € quand le nom de la colonne cible contient la suite de lettres eur, en majuscules ou en minuscules. C'est une commodité qui vise un nom comme « chiffre_affaires_eur », mais elle se déclenche aussi sur « valeur », « heures » ou « couleur ». Les valeurs au-delà de mille sont abrégées en milliers, avec une décimale.

Le rendu du PNG utilise les polices installées sur ta machine ; l'image peut donc différer légèrement d'un ordinateur à l'autre.

Note L'image est toujours sur fond sombre. Le graphique exporté ne suit pas le thème de l'application. À savoir avant de le poser sur une page blanche : dans ce cas, prends le SVG et change le fond dans un éditeur.

PDF — le rapport texte

Le PDF n'est pas une mise en page graphique : c'est un rapport en texte à espacement fixe, écrit directement par Beaver.

Les caractéristiques du document
CaractéristiqueValeur
Format de pageA4
PoliceCourier, corps 9
Lignes par page46
PaginationAutomatique, autant de pages que nécessaire

Le contenu, dans l'ordre : l'en-tête, avec le nom de l'analyse, le modèle et son fournisseur, la colonne cible, l'horizon et la fréquence, la période couverte par l'historique et son nombre de points ; les prévisions, un tableau daté avec date, série, valeur et les trois valeurs de fourchette ; l'analyse avancée, avec la décomposition par série, le nombre d'écarts notables puis les dix premiers, l'importance des variables avec sa méthode et sa fiabilité puis les dix premières, et les constats de dérive ; le backtest, avec le classement des modèles évalués et leurs mesures ; l'ensemble, avec les modèles combinés, leur poids et l'état de validation ; les scénarios, nom et nombre de points ; les notes, avec pour chacune sa date, son type, son titre et les quatre premières lignes de son contenu.

Les titres de section du document sont écrits sans accent.

Attention Le PDF est un résumé, pas une archive. Il ne garde que les dix premiers écarts notables, les dix premières variables et les quatre premières lignes de chaque note. Pour l'intégralité, prends le JSON ou le classeur Excel.

Copier — le collage rapide

Cette entrée n'écrit aucun fichier : le moteur produit un texte, l'interface le pose dans le presse-papiers.

Le texte produit : quatre lignes d'en-tête — nom de l'analyse, modèle, colonne cible, horizon et fréquence —, une ligne vide, puis un tableau séparé par des tabulations avec date, série, valeur et les trois valeurs de fourchette, une ligne par échéance. Les lignes d'analyse avancée, de backtest et d'ensemble suivent, dans la même forme que le PDF.

Le séparateur par tabulation est ce qui rend ce format utile : un collage direct dans un tableur remplit les colonnes toutes seules. Les cellules de texte y sont protégées de l'injection de formule comme dans le CSV.

Ce que le presse-papiers ne contient pas : l'historique fourni, les scénarios détaillés, les annotations et les notes. C'est le seul export volontairement partiel.
