Prompts système

Les instructions données au modèle avant ton premier message : son rôle, la façon d'employer les outils, le format attendu de ses réponses. Beaver en fournit par défaut, et ils sont consultables, modifiables, remplaçables et désactivables.

À ne pas confondre avec tes propres consignes : le prompt système vient de Beaver, AGENTS.md vient de toi. Voir Instructions permanentes.

Deux modes, deux niveaux

Deux modes, selon la façon de travailler : Chatbot pour une conversation sans outils, Agentique pour le travail avec outils. Et deux niveaux de détail pour chaque mode : Compact, version resserrée, et Détaillé, version complète.

Soit quatre prompts par portée, chacun réglable indépendamment.

Le niveau est choisi automatiquement

Point non évident : le niveau dépend du modèle employé, pas d'un réglage manuel. Le choix se fait à partir de la taille du modèle — un petit modèle reçoit la version compacte, un grand la version détaillée.

Pourquoi Un prompt long occupe une part importante du contexte d'un petit modèle : il le noie plutôt qu'il ne le guide. La version compacte lui laisse de la place pour travailler.

Le texte réellement employé peut avoir trois provenances : celui de Beaver, celui du modèle, ou le tien.

Attention Sans prompt système, le modèle ne sait ni comment employer les outils, ni quel format adopter. L'état Désactivé est utilisable pour un usage précis, pas comme réglage courant.
Un champ vide désactive Enregistrer un prompt personnalisé vide ne restaure pas le prompt d'origine : ça désactive le prompt système. C'est volontaire — vider le champ est un moyen explicite de le couper. Pour revenir au défaut, utilise « Restaurer ».

Les prompts natifs des modèles locaux

Un modèle Ollama peut embarquer son propre prompt système, défini par son auteur. Beaver préserve ce prompt natif avant toute personnalisation, dans un stockage dédié, et indique si un prompt natif est disponible pour le modèle en cours.

Tu peux donc choisir explicitement entre le comportement voulu par l'auteur du modèle et celui de Beaver : personnaliser un modèle ne détruit pas ce qu'il portait.

Modifier, désactiver, restaurer

Trois opérations, dans Réglages › Prompt système : enregistrer un contenu personnalisé, désactiver le prompt, restaurer le prompt d'origine.

Deux garde-fous accompagnent ces opérations : un avertissement avant de remplacer un prompt déjà personnalisé, et une copie dans le presse-papier en un clic avant que le texte soit perdu.
