Pièces jointes

Tu peux attacher des fichiers à un message : l'agent y accède pour la conversation. Cette page décrit les limites, le mécanisme qui protège chaque fichier joint, et le cas où joindre ne sert à rien.

Les limites

Valeurs de référence
LimiteValeur
Pièces jointes15
Taille d'une pièce jointe20 Mo
Longueur d'un chemin4 096 octets

Un fichier au-delà de 20 Mo est refusé. S'il se trouve dans un dossier autorisé, laisse-le où il est : l'agent le lira avec ses outils.

Comment l'accès est autorisé

Joindre un fichier ne rend pas ce fichier librement accessible. Chaque chemin reçoit une autorisation signée :

  • elle est calculée avec une clé conservée dans le coffre chiffré ;
  • elle est vérifiée à chaque accès ;
  • le chemin est résolu — liens et raccourcis compris — avant d'être autorisé ;
  • une autorisation qui ne correspond pas donne l'erreur attachment_access_denied.
Une pièce jointe donne accès à un seul fichier Joindre un fichier autorise l'accès à ce fichier précis, pas au dossier qui le contient. Un chemin fabriqué ou modifié ne passe pas.

Ce qui se passe au redémarrage

Les autorisations peuvent être restaurées au lancement suivant, pour que les pièces jointes d'une conversation reprise restent accessibles.

La pièce jointe sert au fichier isolé, hors de tes dossiers de travail : un document reçu, une capture, un export téléchargé.

Inutile de joindre un fichier du projet Si le fichier se trouve dans un dossier auquel l'agent a accès, il peut le lire directement — sans limite de 20 Mo ni de nombre. Voir Répertoire de travail.
