Le parcours d'accueil

Au premier démarrage, Beaver te fait traverser quatre ou cinq écrans : préférences, import depuis un autre assistant, connexion d'un fournisseur, et installation du moteur local si nécessaire. Rien n'y est obligatoire.

Rien n'est définitif Aucune étape du parcours d'accueil n'est obligatoire. Tout ce qui y est proposé se retrouve dans les réglages.

Vue d'ensemble

Le parcours compte quatre ou cinq étapes, présentées en diapositives horizontales. La cinquième — Ollama — n'apparaît que si Ollama n'est pas déjà disponible sur ta machine. Aucune étape n'est bloquante : tu peux traverser le parcours sans rien configurer et tout faire plus tard dans les réglages.

Étape 1 — Bienvenue

Un écran de présentation avec l'illustration du castor, un titre, une description et un bouton pour commencer. Rien à saisir.

Étape 2 — Préférences

Deux réglages, et deux seulement : le thème, parmi ceux disponibles, et la langue, parmi les sept langues de l'interface. On les retrouve ensuite dans Réglages › Général.

Étape 3 — Import depuis un autre assistant

Cette étape propose de reprendre les instructions, les skills et les règles depuis une autre application d'agent déjà installée. Neuf sources sont reconnues, détaillées dans Importer d'un autre agent.

Étape 4 — Connexion d'un fournisseur

Une grille de cartes, une par fournisseur de modèles, avec son icône, son nom et une courte description. Seuls les fournisseurs de catégorie LLM sont affichés, 32 au maximum. Ceux qui sont déjà configurés portent la mention « Connecté ».

Tu sélectionnes une carte, tu saisis la clé, tu enregistres ; un lien mène à la page de création de clé du fournisseur. La clé saisie est effacée du champ dès que tu quittes l'étape.

Sans clé API Tu peux traverser cette étape sans rien saisir. Beaver fonctionne avec un modèle local, sans compte ni clé.

Étape 5 — Ollama, si nécessaire

Cette étape n'apparaît pas si un démon Ollama est déjà disponible, ou si le binaire est déjà présent dans le dossier de données. Sinon, elle propose le téléchargement et l'installation d'Ollama, et peut être passée : l'application reste utilisable avec des modèles distants uniquement. Le détail du téléchargement est dans Premier lancement.

Revenir en arrière, passer une étape

Les étapes Import et Fournisseur proposent un retour en arrière. L'enchaînement s'adapte : si l'étape Ollama n'est pas nécessaire, valider l'étape Fournisseur termine directement le parcours.

Le mode de permission n'est pas demandé ici Le parcours d'accueil ne propose pas de choisir un mode de permission : l'application démarre en Accès complet, où l'agent exécute ses outils sans demander confirmation. C'est à changer dans les réglages si tu préfères valider chaque action.
