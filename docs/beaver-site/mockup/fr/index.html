02 / Le harnais

À ta main.Vraiment.

Pas un fork. Ton Beaver. Une extension n'ajoute pas seulement : elle retire et elle remplace. Le même Beaver, remodulé par toi.

mon-extension.ts — beaverApi: "1"
export default defineExtension({
  activate(beaver) {
    // ton outil, à côté de ceux de Beaver
    beaver.registerTool(monOutil)

    // ta vue, dans son interface
    beaver.ui.register({ type: 'tab', id: 'crm' })

    // et ce que tu recouvres — API avancée
    beaver.unstable.registerReplacement(monBash)
  },
})
01

Remplace ses outils

Son outil bash ne te convient pas ? Recouvre-le avec le tien, via l'API avancée. L'agent ne verra que le tien.

02

Réécris son cerveau

Le prompt système se remplace, se désactive, ou revient à celui du modèle — depuis les réglages, séparément pour le mode agent et le mode chat.

03

Ajoute tes panneaux et tes vues

L'interface n'est pas figée : tes panneaux, tes boutons et tes vues prennent leur place à côté des siens.

04

Sans jamais tout casser

Chaque extension tourne dans son propre processus, hors du cœur de Beaver. L'une plante, Beaver continue. Et rien ne s'active sans ton accord explicite.
