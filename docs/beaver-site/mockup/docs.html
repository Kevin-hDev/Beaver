Modes de permission

Chaque session d'agent tourne dans l'un des trois modes de permission. Le mode choisi détermine ce que Beaver peut faire sans te demander ton accord. Tu peux en changer à tout moment depuis la session, et définir un mode par défaut dans les réglages.

Accès complet

L'agent exécute ses outils librement : lecture et écriture de fichiers, commandes shell, actions Git, appels aux connecteurs. C'est le mode le plus fluide pour les longues tâches autonomes — à réserver aux projets de confiance.

Demande d'approbation

Chaque action sensible — écriture, commande shell, suppression — déclenche une demande d'approbation dans la conversation. Tu vois exactement ce que l'agent s'apprête à faire, tu acceptes ou tu refuses. C'est le mode recommandé au quotidien.

Chatbot

Aucun outil actif : Beaver répond uniquement en texte, comme un chat classique. Utile pour explorer, rédiger ou raisonner sans rien toucher sur ta machine.

Sécurité Quel que soit le mode, tes clés d'API restent dans le coffre chiffré XChaCha20-Poly1305. Elles ne sont exposées ni à l'interface ni à l'agent : le cœur Rust les charge au moment de l'appel, puis efface sa copie en mémoire.

Définir le mode par défaut

# Réglages → Agent → Mode par défaut
$ cat ~/.local/share/cl-go-dash/agent-settings.json
{ "permission_mode": "approval" }
