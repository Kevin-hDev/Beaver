Permission modes

Every agent session runs in one of three permission modes. The mode you choose determines what Beaver can do without asking you first. You can switch at any time from the session, and set a default mode in the settings.

Full access

The agent runs its tools freely: reading and writing files, shell commands, Git actions, connector calls. It's the smoothest mode for long autonomous tasks — keep it for projects you trust.

Approval required

Every sensitive action — a write, a shell command, a deletion — raises an approval request in the conversation. You see exactly what the agent is about to do, and you accept or refuse. This is the mode recommended for day-to-day work.

Chatbot

No tools on your machine: Beaver answers in text and can at most search the web. Useful for exploring, drafting or reasoning without touching anything on your disk.

Security Whatever the mode, your API keys stay in the encrypted XChaCha20-Poly1305 vault. They are exposed neither to the interface nor to the agent: only the Rust core touches them, no command can read them out, and the copy used for each call is wiped after use.

Setting the default mode

# Settings → Agent → Default mode
$ cat ~/.local/share/cl-go-dash/agent-settings.json
{ "permission_mode": "manual" }   # values: "auto" · "manual" · "chat"
