02 / Le harnais

À ta main.Vraiment.

Pas un fork. Ton Beaver. Une extension n'ajoute pas seulement : elle retire et elle remplace. Le même Beaver, remodulé par toi.

mon-extension.ts — beaverApi: "1"
export default {
  // tes outils, à côté de ceux de Beaver
  tools: [monTool, maRecherche],

  // tes panneaux et tes vues dans l'interface
  panels: [{ id: 'crm', title: 'Mon CRM' }],

  // et ce que tu remplaces purement et simplement
  replace: {
    tool: 'bash',
    systemPrompt: monPrompt,
  },
}
01

Remplace ses outils

Son outil bash ne te convient pas ? Mets le tien à la place. L'agent ne verra que le tien.

02

Réécris son cerveau

Le prompt système se remplace, se désactive, ou revient à celui du modèle — séparément pour le mode agent et le mode chat.

03

Ajoute tes panneaux et tes vues

L'interface n'est pas figée : tes panneaux, tes boutons et tes vues prennent leur place à côté des siens.

04

Sans jamais tout casser

Les extensions tournent dans un hôte Node séparé. L'une plante, Beaver continue. Et rien ne s'active sans ton accord explicite.

Tu viens d'ailleurs.Deux minutes.
