Look without leaving

The file tree lets you browse the conversation's working directory, and one click opens the file's preview in the side panel. This page says what can be previewed, up to what size, and what happens beyond that.

The file tree

It shows the conversation's working directory. A click on a file opens its preview in the side panel. What the tree shows therefore depends on the working directory chosen for that conversation.

Change watching

  • Changes on disk are detected automatically, through each system's native notifications.
  • A grouping delay of 200 milliseconds avoids recomputing the display on every write: a build that touches a hundred files does not cause a hundred refreshes.

The previews

Four families, each with its own handling:

  • Text — direct display, with syntax highlighting following the chosen code theme.
  • Images — direct display.
  • Spreadsheets — tabular rendering, with a sheet picker for workbooks that have several.
  • Documents — content extraction, for the docx and pdf formats.

On top of that come link previews: when a reply contains a URL, Beaver can show a summary of it.

The size limits

Beyond the three caps in the table above:

  • 500 rows displayed by default for a spreadsheet, 5,000 at most.
  • Path length: 4,096 characters.
  • Batch existence check: 500 files per call.

Opening in an external editor

  • Beaver detects the installed editors and offers to open the file in one of them.
  • Detection is specific to each system: macOS, Windows and Linux each have their own.
  • The editor's path is validated before launch.
