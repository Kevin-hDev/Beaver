Consulter sans sortir

L'arbre de fichiers te fait naviguer dans le répertoire de travail de la conversation, et un clic ouvre la prévisualisation du fichier dans le panneau latéral. Cette page dit ce qui est prévisualisable, jusqu'à quelle taille, et ce qui se passe au-delà.

L'arbre de fichiers

Il affiche le répertoire de travail de la conversation. Un clic sur un fichier ouvre sa prévisualisation dans le panneau latéral. Ce que l'arbre montre dépend donc du répertoire de travail choisi pour cette conversation.

La surveillance des modifications

  • Les changements sur le disque sont détectés automatiquement, via les notifications natives de chaque système.
  • Un délai de regroupement de 200 millisecondes évite de recalculer l'affichage à chaque écriture : une compilation qui touche cent fichiers ne provoque pas cent rafraîchissements.

Les prévisualisations

Quatre familles, chacune avec son traitement :

  • Texte — affichage direct, avec coloration syntaxique selon le thème de code choisi.
  • Images — affichage direct.
  • Tableurs — rendu tabulaire, avec choix de la feuille pour les classeurs qui en comptent plusieurs.
  • Documents — extraction du contenu, pour les formats docx et pdf.

S'y ajoutent les aperçus de liens : quand une réponse contient une URL, Beaver peut en afficher un résumé.

Attention Documents : docx et pdf uniquement. Un .doc ancien, un .odt ou un .rtf ne sont pas prévisualisables.

Les limites de taille

Au-delà des trois plafonds du tableau ci-dessus :

  • 500 lignes affichées par défaut pour un tableur, 5 000 au maximum.
  • Longueur d'un chemin : 4 096 caractères.
  • Vérification d'existence en lot : 500 fichiers par appel.

Note Deux mégaoctets pour le texte : au-delà, ouvre le fichier dans un éditeur externe. Un journal ou un jeu de données dépasse vite cette taille.

Ouvrir dans un éditeur externe

  • Beaver détecte les éditeurs installés et te propose d'ouvrir le fichier dans l'un d'eux.
  • La détection est propre à chaque système : macOS, Windows et Linux ont chacun la leur.
  • Le chemin de l'éditeur est validé avant lancement.
