Twenty keys

Beaver has twenty shortcuts, and not one more. This page gives them all, with their key on each system and the precise place where each one works — because half of the “shortcuts that don't work” are in fact shortcuts used in the wrong place.

The command key on your system

Beaver uses two modifier keys, whose name changes from one system to another.

The two modifiers, by system

Three scopes, not to be mixed up

A Beaver shortcut always belongs to one of these three families.

  • Everywhere in the app — sidebar, navigation, conversation search, settings, text size. These shortcuts listen to the whole window and set no condition.
  • In the conversation displayed — terminal, preview, in-conversation search, focus in the message area, clone tabs, changing the permission mode.
  • In an input field — sending, new line, stopping the answer, submitting or cancelling a message edit. Those work only with the cursor in the field concerned, which is the exact opposite of the previous rule.

Two shortcuts from the second family — ⌘J and ⌥⌘B — are ignored when no conversation is active, and when the cursor is in an input field: message area, search field, editor. Without that precaution, typing the letter J in a message would open the terminal. Shift+Tab applies the same exclusion, also works on the home screen of a new conversation, but not in a subagent conversation.

Two behaviors that surprise people

⌘1 to ⌘9 do not switch conversation. They choose a tab inside the current conversation, and those tabs only exist for clone groups. With no clone, these nine shortcuts have nothing to select. See Cloning a conversation.

⌘J sometimes creates instead of toggling. If the terminal has never been opened in this conversation, the shortcut opens a first terminal tab in the working directory, instead of simply showing or hiding the panel. See Built-in terminal.

Stopping an answer: Esc twice

The first Esc stops nothing: it arms a confirmation, valid for 3 seconds. The second Esc within that window stops the answer. Past the 3 seconds, the confirmation lapses and you have to start over.

The stop button in the input field, on the other hand, stops in a single click, with no confirmation: aiming and clicking is already a deliberate gesture, whereas Esc often comes from a reflex.

The list cannot be changed

Note Beaver's shortcuts are fixed. The Settings › Keyboard Shortcuts screen shows them for reference, it does not let you change them. There is no hidden option elsewhere.

The shortcuts provided by the system

These are the ones people look for first, and they do not come from Beaver.

  • macOS — ⌘Q actually quits the app. The red dot merely hides the window.
  • Windows and Linux — the close button closes the app.

The detail of that difference is in First launch.
