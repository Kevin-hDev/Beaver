Appearance, languages and startup

The Preferences section sets what you see and how you navigate. This page describes the fields: where they are, what their defaults are, and where their value is saved — that last point having a concrete consequence the day you reinstall.

General — appearance

Four settings, gathered in a first card.

Theme — “App appearance”. A grid of tiles, each showing a miniature preview. Seven choices ship with Beaver.

SystemFollows the operating system's setting

The System choice is shown last, with a tile cut in two — half light, half dark. It fixes nothing: it follows the system's light or dark mode and switches with it.

An installed extension can add its own themes. They appear in the same grid, after the seven native themes, with the name of the extension providing them shown under the label.

Font size — “Base interface size in pixels”. A numeric field with two arrows. The value is bounded from 10 to 24 pixels, 18 by default. A value outside the bounds is brought back into range rather than refused. The up and down arrow keys change it by one pixel. This setting also has its shortcuts, described further down.

Font family — “Font used in the app”. Seven choices: System Default, JetBrains Mono, Helvetica Neue, Menlo, UI Monospace, Pacifico, Rancho. The last two are handwriting faces; the middle three are fixed-width fonts, suited to code.

Code theme — “Coloring of code blocks and previews”. Five choices: Défaut, GitHub, One Dark Pro, Tokyo Night, Catppuccin. Each exists in a light and a dark variant, chosen automatically according to the application's theme. A live preview is shown just below the card: a colored code excerpt that updates as you change it.

What each theme changes visually is detailed in Themes and appearance.

General — languages

Two distinct settings, which don't concern the same thing.

Language — “Interface language”. Beaver's seven languages: English, Français, Deutsch, Español, Italiano, 中文, 日本語. The change is immediate, with no restart.

LLM response language — “Language the AI model will respond in”. The same seven languages, plus an empty value shown as —, which is the default. With no value here, the model answers as it sees fit — most often in the language of the question.

Link previews — “Show a preview card for URLs in chat”. A switch, on by default.

Note Two languages, two settings. Language changes Beaver's menus and texts. LLM response language asks the model to answer in a given language. The two are independent: you can work in a French interface with an agent that answers in English, or the other way round. The seven languages are detailed in Languages.

General — startup

Two switches, in a last card.

Launch at startup — “Open Beaver automatically at system startup”. Off by default. Turning it on or off triggers a synchronisation with the operating system: that's where Beaver adds itself to, or removes itself from, the list of programs launched when the session opens.

Start hidden — “Start in the background without opening the window”. Off by default, and unusable while the previous one is off: the switch is then greyed out.

This dependency is enforced at three levels: in the display, on saving, and a third time on the engine side, which resets the value whatever happens if launch at startup is off. In other words, there is no path — not even a configuration file edited by hand — that produces a “start hidden” without a “launch at startup”.

Mascot tab

The tab opens on an animated preview of the selected character, with its name and a status mention: “Animated preview” when the animation is running, “Animation paused” otherwise.

Then a “Settings” card with two controls:

  • Show mascot — “Keep the mascot visible above the desktop and other applications”. Off by default.
  • Size — “Adjust the mascot size on screen”. A slider graduated from 70% to 140%, 100% by default. The percentage value is shown next to the slider.

Finally a “Collection” section: a grid of eight characters, each with its portrait, its name and a one-sentence description. The active character carries the mention “Selected”.

Keyboard Shortcuts tab

A plain list: the action on the left, the key combination on the right. The keys shown adapt to the system — Cmd on Mac, Ctrl elsewhere; Option on Mac, Alt elsewhere.

This screen is read-only. No shortcut can be changed, and there is no button to change one.

Two remarks about this list. “Stop response” takes two presses of Escape, which the screen shows as two keys side by side: it isn't a typo. And the last three shortcuts drive the same setting as “Font size” in the General tab — enlarging the interface from the keyboard moves the value in the settings, and the other way round.

Warning Keyboard shortcuts can't be customised. The tab displays them, it doesn't change them, and there is no other way to change one in the application. Each shortcut is explained in Keyboard shortcuts.

Where each setting is saved

Not every setting in this section is saved in the same place, and some don't follow when you copy your data folder.

Where each preference is written
SettingSaved
ThemeOn the application side, on this machine
Font sizeOn the application side, on this machine
Font familyOn the application side, on this machine
Code themeOn the application side, on this machine
Interface languageOn the application side, on this machine
LLM response languageIn the configuration file of the data folder
Link previewsIn the configuration file and on the application side
Launch at startupIn the configuration file and in the operating system
Start hiddenIn the configuration file
Mascot (enabled, size, character, position)In the configuration file
Warning The theme and the interface language aren't in your data folder. They are saved on the application side, along with the appearance and the text size. A reinstall, or a data folder copied to another machine, brings them back to their default value. The conversations, the keys and the agent settings do follow.

Common pitfalls

The most common surprises in the Preferences section
SymptomCauseFix
“I set the interface to French but the agent answers in English”These are two distinct settingsFill in LLM response language in General
“Start hidden is greyed out”It depends on Launch at startup, which is offTurn on launch at startup first
“I turned on start hidden but the window opens anyway”Launch at startup was turned off afterwards, which resets start hiddenTurn both back on
“The text is unreadable, too small or too big”The size is bounded between 10 and 24 pixelsCmd/Ctrl + 0 restores 18 pixels
“My themes and my language disappeared after reinstalling”They aren't in the data folderSet them again; expected behavior
“A theme I didn't install appears in the grid”It comes from an extension; the name of its source is written under the tileRemove it by disabling the extension
“The mascot has disappeared from my screen”It's off by default, or moved out of the visible areaTurn it back on in Preferences › Mascot
“I want to change a keyboard shortcut”That isn't provided for in the applicationNo fix for now
