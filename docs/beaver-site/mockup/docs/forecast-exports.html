Getting a forecast out of Beaver

Seven formats, from the flat table to the printable report. This page says what each one really contains, where the file lands and how it is named — because from one format to another, it isn't the same thing that comes out.

Key point All seven outputs exist and work: CSV, Excel, PNG, SVG, JSON, PDF and copy to clipboard. The file goes to your downloads folder, named after the analysis.

The seven outputs, and where to find them

The button carries the label Export and opens a menu of seven entries.

The button appears in two places, and it's the same one: in the footer of the Forecast panel as soon as an analysis is open, and in the toolbar of the Report section of the Forecast workspace window.

Three possible messages after the action: “Export saved”, a file was written; “Export copied”, the text is in the clipboard; “Export failed”, the export failed, with no further detail.

Where the file goes, and what it's called

The destination is the system's downloads folder. When that can't be found, Beaver falls back to an exports folder created as needed under its own data folder.

The file's name always follows the same shape: the analysis's name cleaned up, a hyphen, the first eight characters of its identifier, then the extension. The cleaning is strict: only unaccented letters and digits are kept, in lower case; spaces, hyphens and underscores become hyphens; everything else is removed, accents included; consecutive hyphens are reduced to one; the result is cut at 64 characters. If nothing is left, the name becomes forecast.

The eight identifier characters at the end prevent two analyses with the same name from overwriting each other. An analysis can only be exported from the conversation it belongs to: the permission is checked before any reading.

Warning Accents disappear from the file name. “Prévision CA — été 2026” becomes prvision-ca-t-2026: accents aren't transliterated, they're removed. The file's content, however, keeps the accents.

What's in every export

Whatever the format, the export starts from the same assembly: the complete analysis and its notes. Notes are therefore never left out, even in a raw-data export.

The range headers adapt to the confidence level requested. They aren't fixed: they are computed from the level chosen.

CSV — the flat table

A single table, ten columns, stacking everything the analysis contains: section, name, date, series_id, value, the three range headers, then text and source.

What the section column says
ValueWhat the row carries
historyA point from the history supplied
predictionA predicted point, with its range
scenarioA point from a scenario, whose name is in name
annotationAn annotation placed on the chart
noteA note attached to the analysis
residual_anomalyA notable deviation found after the calculation
variable_importanceThe weight of an explanatory variable
driftA drift finding on a series
ensemble_memberA model and its weight in an ensemble
Security Your exports can't execute a formula. A text cell starting with =, +, - or @ is neutralised before writing, in the CSV as in the Excel workbook: a spreadsheet opening the file shows the text instead of executing it. That's why some cells appear with a leading apostrophe.

Each sheet gets a frozen header row, an auto-filter and a column-width adjustment capped at 52 characters. The workbook is likewise protected from formula injection: a note title written like a formula stays text.

Key point The workbook carries your starting data. Its last sheet, Input data, contains the original file row by row. It's the only export that lets you redo all the work from a single file.

JSON — everything, without loss

The file contains three keys at the root: analysis, the entire analysis as it is saved; notes, the attached notes; quantile_labels, the three range headers corresponding to the confidence level.

The file is formatted readably, not compacted. It is the only format that loses nothing: all the others select, round or lay out. It's the format to recommend for feeding another program.

PNG and SVG — the chart's image

Both output the same drawing: the SVG is written as is, the PNG is its rendering.

The characteristics of the exported image
CharacteristicValue
Dimensions1,400 × 760 pixels
BackgroundDark, whatever your theme
TitleThe analysis's name
SubtitleModel, target column, horizon, number of points
CurvesHistory in light grey, forecast in orange with one dot per step, scenarios in dotted blue
Confidence areaA translucent orange band around the forecast
Reference marksDated horizontal axis and horizontal grid with values
LegendThree entries: Historique, Prevision, Confiance

The legend is written in French inside the image, without going through the translations — and the word “Prevision” appears there without its accent.

One quirk worth knowing: the value axis adds a € symbol when the target column's name contains the letter sequence eur, in upper or lower case. It's a convenience aimed at a name like “chiffre_affaires_eur”, but it also fires on “valeur”, “heures” or “couleur”. Values above a thousand are abbreviated in thousands, with one decimal.

The PNG rendering uses the fonts installed on your machine; the image can therefore differ slightly from one computer to another.

Note The image is always on a dark background. The exported chart doesn't follow the application's theme. Worth knowing before dropping it on a white page: in that case, take the SVG and change the background in an editor.

PDF — the text report

The PDF isn't a graphic layout: it's a report in fixed-width text, written directly by Beaver.

The document's characteristics
CharacteristicValue
Page formatA4
FontCourier, 9 pt
Lines per page46
PaginationAutomatic, as many pages as needed

The content, in order: the header, with the analysis's name, the model and its provider, the target column, the horizon and the frequency, the period covered by the history and its number of points; the forecasts, a dated table with date, series, value and the three range values; the advanced analysis, with the decomposition per series, the number of notable deviations then the first ten, the variable importance with its method and its reliability then the first ten, and the drift findings; the backtest, with the ranking of the evaluated models and their metrics; the ensemble, with the combined models, their weight and the validation status; the scenarios, name and number of points; the notes, each with its date, its type, its title and the first four lines of its content.

The document's section titles are written without accents.

Warning The PDF is a summary, not an archive. It only keeps the first ten notable deviations, the first ten variables and the first four lines of each note. For everything, take the JSON or the Excel workbook.

Copy — the quick paste

This entry writes no file: the engine produces a text, the interface puts it in the clipboard.

The text produced: four header lines — analysis name, model, target column, horizon and frequency — a blank line, then a tab-separated table with date, series, value and the three range values, one line per step. The advanced-analysis, backtest and ensemble lines follow, in the same shape as the PDF.

The tab separator is what makes this format useful: pasting directly into a spreadsheet fills the columns on its own. Text cells there are protected from formula injection as in the CSV.

What the clipboard doesn't contain: the history supplied, the detailed scenarios, the annotations and the notes. It's the only deliberately partial export.
