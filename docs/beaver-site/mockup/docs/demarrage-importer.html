Importer d'un autre agent

Si tu utilises déjà Claude Code, Codex ou un autre agent, tu n'as pas à tout réécrire. Beaver détecte neuf applications installées sur ta machine et reprend leurs instructions, leurs règles et leurs skills.

Ce que fait l'import

L'import reprend trois types de contenu : le document d'instructions, c'est-à-dire le fichier que l'assistant lit à chaque conversation ; les règles, des fichiers d'instructions rangés dans un dossier rules/ ; et les skills, des procédures rangées dans un dossier skills/.

Ce qui n'est pas importé L'import reprend tes instructions, tes règles et tes skills. Il ne reprend ni tes conversations, ni tes clés API, ni tes connecteurs, ni tes réglages d'interface.

La détection repose sur la présence d'un dossier à un emplacement précis. Ce tableau dit lequel, pour chaque source.

Deux particularités méritent d'être signalées. Hermes Agent n'a pas de document d'instructions repris — uniquement ses règles et ses skills. Et OpenClaw est le cas le plus complexe : plusieurs espaces de travail sont examinés, et le document retenu est le premier AGENTS.md trouvé.

Deux sources dépendent de variables d'environnement, ce qui explique la plupart des non-détections : OpenCode est cherché dans $XDG_CONFIG_HOME/opencode, ou ~/.config/opencode si la variable n'est pas définie ; Kimi Code dans $KIMI_CODE_HOME, ou ~/.kimi-code par défaut, plus trois emplacements complémentaires.

Assistant non détecté La détection repose sur la présence d'un dossier à un emplacement précis. Si ton assistant est installé ailleurs — notamment via une variable d'environnement pour OpenCode et Kimi Code — il ne sera pas trouvé.

Ce qui est repris, et où ça atterrit

Le document d'instructions est copié dans le AGENTS.md de Beaver, avec une empreinte de la source pour détecter les modifications ultérieures. Les règles et les skills sont copiés dans les dossiers correspondants du dossier de données. Chaque document importé peut ensuite être activé ou désactivé individuellement, sans être supprimé.

Comment ça se passe

  • L'assistant d'import détecte les applications présentes en cherchant leurs dossiers.
  • Tu choisis les sources à reprendre, et ce que tu veux de chacune.
  • Beaver copie le contenu retenu.
  • Une sauvegarde de l'état antérieur est conservée.

L'import est proposé pendant le parcours d'accueil, et reste disponible ensuite.

Les sauvegardes

Cinq sauvegardes au maximum sont conservées par document. Elles vivent dans agent-import-backups/, dans le dossier de données, et le registre de ce qui a été importé est dans external-agent-sources.json.

Rien n'est écrasé sans sauvegarde Beaver conserve jusqu'à cinq versions antérieures de chaque document importé. Ton fichier d'instructions précédent n'est pas perdu.

Les limites

Elles ne sont pas décoratives : un dossier de skills volumineux sera tronqué, et il vaut mieux savoir pourquoi.
