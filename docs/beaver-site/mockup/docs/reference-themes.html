The look of your Beaver

Six themes, seven fonts, five code colorings and an adjustable text size. Everything changes live, without restarting the app, and everything lives in the same place: Settings › General.

The themes

Six themes, plus a System option. Two are light, four are dark. Each theme is a complete palette, not just an accent color: switching from one to another is immediate.

The System mode

The System option follows your operating system's light/dark setting. It switches between Light and Dark only.

Warning The four colored themes — Emerald Night, Frosted Cobalt, Astral Mist, Crimson Eclipse — are never chosen automatically. If you like Emerald Night and you set “System”, you will not get Emerald Night back at night, but the standard Dark theme. Those themes are chosen explicitly.

The text size

It is set by typing a value directly or by one-pixel steps, and is also driven from the keyboard with ⌘+, ⌘- and ⌘0 (see Keyboard shortcuts).

The bounds of the text size
MarkerValue
Minimum10 px
Maximum24 px
Default18 px
Step1 px

Any value outside the bounds is brought back into the range, and an invalid entry goes back to 18 px. A value that changes on its own after being typed is therefore not a display fault.

The font

Seven families on offer. Four are monospaced — every character takes the same width, which helps for reading code in answers — and two are handwriting fonts, to be kept for decorative use.

Code coloring

Five coloring themes for the code blocks in the agent's answers: Défaut — this one is shown in French whatever your language —, GitHub, One Dark Pro, Tokyo Night and Catppuccin.

Note Each one has a light variant and a dark variant, chosen automatically according to the app's theme. So you only have one setting to make, not one for light and one for dark. The settings screen shows a preview of both variants side by side on a code excerpt.

Where each thing is set

Everything is in Settings › General, except for what concerns the mascot, which has its own tab — see Mascot.

The theme and the language are also offered during the onboarding journey, on the first launch.
