A real shell, inside the application

Not an output console: a full interactive shell, attached to the conversation's working directory. It saves you the round trip to an external application when you want to check for yourself what the agent has just done.

Opening a terminal

  • Shortcut ⌘J on macOS, Ctrl+J on Windows and Linux.
  • If no terminal has ever been opened in this conversation, the shortcut creates one in the working directory. Otherwise, it simply toggles the display.
  • The shortcut has no effect outside a conversation, or when the cursor is in an input field.

Which shell is launched

macOS and LinuxThe shell set by the SHELL variable, or /bin/bash as a fallback

On macOS and Linux, the shell's path is validated before launch: an invalid path is refused rather than executed. On Windows, no setting lets you prefer cmd.exe or PowerShell 7: it is powershell.exe, resolved through a validated system path.

What Beaver changes in the environment

A single place decides the shell's environment, and it does two things.

  • It sets TERM=xterm-256color and COLORTERM=truecolor.
  • It removes six variables set by the application launcher: NO_COLOR, NODE_DISABLE_COLORS, FORCE_COLOR, COLOR, CLICOLOR, CLICOLOR_FORCE.

The reason is concrete: without it, a launcher that disables color made the output of vite, cargo and the Tauri command line uniformly gray in the integrated terminal.

$ echo $TERM
xterm-256color

EDITOR, on the other hand, is passed through as is: Beaver does not touch it.

The tabs

  • The terminal has multiple tabs.
  • Open tabs are kept between two launches, in terminal-tabs.json.

The limits

Two different limits carry the value 16: do not confuse them. One counts the live processes across the whole application, the other the tabs saved in a conversation.

The terminal's caps, and what each one covers
LimitValueScope
Live terminal processes16Global, across all conversations
Saved tabs per group16Per conversation
Tab groups128Global
Saved tabs in total256Global
Size of a write65,536 bytesPer write

Beyond sixteen processes, opening is refused with an explicit message. The limit is deliberate: every live terminal is a system process, and an application that opens them without counting eventually exhausts the machine's resources. A saved tab whose process is not running does not use up that quota.

Note Sixteen at most, across all conversations. If opening is refused, go and close some tabs — including in conversations other than the one you are in.

Your terminal and the agent's

These are two separate mechanisms, and it is a common confusion.

  • The integrated terminal is yours. What you type there is not seen by the agent.
  • The bash tool is the agent's. Its commands run separately, under the control of the permissions.

The two share the conversation's working directory, nothing more. See Terminal and shell for the agent's tool.
