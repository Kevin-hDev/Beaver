Knowing where the agent stands, without looking

The mascot is an animated character that reflects the agent's state: idle, working, task succeeded, task failed. It lives in its own window, and it stays off until you turn it on.

Note It is off to begin with. The mascot does not appear until you enable it in Settings › Mascot. That is a choice, not a fault.

What it is for

It is not only decorative. On a long task, it tells you at a glance whether the agent is still working or has finished, without you having to go back into the conversation.

Note Keeping an eye out without sitting in front of it: the mascot has its own window. Leave it visible while you work elsewhere, and it will tell you when the agent is done.

The eight characters

Eight characters are available. The beaver, cl-go-beaver, is the default one.

The states

The states follow the events of the conversations in progress. Eight animations exist: idle (Idle), working (Thinking, WorkLaptop), plus ExploreBook, Waiting, Success, Failed and Alert.

  • Up to 32 conversations are tracked at the same time.
  • A success state is shown for 2.2 seconds.
  • A failure state is shown for 2.6 seconds.
  • An alert state is shown for 1.8 seconds.
  • The state takes into account whether the application has focus or not.

The dedicated window

The mascot has its own window, separate from the main one. It can therefore stay visible while you work in another application — that is exactly what makes it useful for watching a long task without keeping Beaver in the foreground.

The settings

A dedicated tab: Settings › Mascot. Three settings, not two.

  • Enabling — off by default. Nothing is shown until you turn it on.
  • Choice of character, among the eight.
  • Size, as a percentage, from 70% to 140%, with a live preview. The default is 100%, and a value outside that range is brought back inside it.
