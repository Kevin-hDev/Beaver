Seven languages, two settings

Beaver speaks seven languages. But there are two separate language settings, and they do not do the same thing: the one for the interface, and the one for the agent's answers. Changing one does not change the other.

Warning Setting the interface to French does not make the agent answer in French. If you want answers in your language, also choose the LLM response language, in the same settings screen.

The interface language

It drives the app's menus, buttons and messages. Seven languages: French, English, German, Spanish, Italian, Chinese, Japanese.

  • The change is immediate, with no restart.
  • The choice is remembered by the app.
  • It is offered during the onboarding journey, and can then be changed in Settings › General.

The agent's response language

The same seven languages, plus an empty option shown as “—”. That empty option means no instruction: the agent answers in whatever language seems appropriate, usually the one your message is written in.

When a language is chosen, the instruction is passed to the model in its instructions.

Note This is an instruction, not a guarantee. A small local model may drift away from it, especially on long or technical answers. The interface language, on the other hand, is guaranteed.

What is not translated

Four categories of text are by nature outside the reach of the interface language setting.

  • The models' answers, which depend on the model and on the language instruction.
  • The error messages returned by remote providers, written by them.
  • The names of models, providers and connectors.
  • The content of your own instruction and memory files.
