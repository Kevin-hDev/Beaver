Reading and writing spreadsheets.

Two tools make up the Spreadsheet / Excel group, optional and off by default. Beaver reads six formats and writes only one.

Careful As long as the group is off, the agent does not know these tools exist. A request like "open this Excel file for me" will end in a workaround — an attempt to read it as plain text, which will fail — rather than in a clear message. It is the most common pitfall in this whole section.

A group to turn on

Reading a spreadsheet

Formats accepted for reading: .xlsx, .xls, .xlsm, .ods, .csv, .tsv.

  • The first row always serves as column headers. This is not configurable.
  • On a workbook, the agent can target a specific sheet — the first one by default — and a range of cells.
  • On a CSV or TSV file, sheet and range are ignored, and the separator is detected automatically by analysing the first line: tab, semicolon or comma.
  • Formulas are returned as they are, as text. The agent sees the formula, not its computed result: asking "what is the total" on a cell containing a sum will return the formula, leaving it to the model to understand or recompute it.
Key point Formulas are not computed: the agent sees =SUM(A1:A5), not the total. To get values, you need a file that contains them, or you let the agent do the calculation itself.

What the agent receives

A structured set containing the name of the sheet read, the list of all the workbook's sheets — so the agent knows there are others —, the headers, the data rows, the total number of rows even when not all of them are passed on, and a truncation flag. The agent therefore knows it has not seen everything, and can ask for the rest.

Reading limits: 500 rows by default, 5,000 at most, and 1,000 columns.

Writing an Excel file

A single format for writing: .xlsx. The agent does not supply a complete file but a list of operations to apply, which makes it possible to edit an existing file without rewriting it.

A brand new file gets a default sheet: there is no need to create one for a single-sheet workbook, and it is even explicitly discouraged. Each operation can target a specific sheet, the first one by default.

What does not exist: computed formulas, charts, pivot tables, filters, conditional formatting, images. The tool writes data and appearance, not advanced Excel objects.

The limits and the protections

Modern office files are compressed archives, and an archive can be crafted to take up a disproportionate amount of room once uncompressed — that is a known attack. Beaver guards against it with a capped source file size, a bounded number of entries, a compression ratio refused beyond a threshold and a limited total uncompressed size.

A protection specific to workbooks comes on top: a sheet can declare enormous dimensions while weighing a few kilobytes. Beaver checks the rows × columns product before loading the sheet and refuses beyond 5 million cells. Without that check, a small file could make the application consume several gigabytes of memory.
