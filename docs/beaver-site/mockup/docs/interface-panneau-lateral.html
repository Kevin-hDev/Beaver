One single thing at a time

The side panel is the area to the right of the conversation. File preview, browser and Forecast share the same space: opening one replaces the other. This is not a bug, it is a deliberate space constraint — and it is the first thing to know before touching it.

Note Opening the browser makes your file preview disappear. Nothing is lost: just switch back to File preview.

What the panel holds

It is there to let you look at things without leaving the thread of the conversation: a file, a web page, a forecast chart.

File preview mode is active by default. Each one has its own page: Files and previews, Integrated browser and Forecast.

Switching from one mode to another

  • A dedicated selector, in the conversation interface.
  • Shortcut ⌥⌘B (Alt+Ctrl+B) to show or hide the panel.
Warning The Settings › Keyboard Shortcuts screen advertises the wrong shortcut for this action. ⌥⌘B is the one that works. See Keyboard shortcuts.

Resizing and hiding

  • The panel width is set by dragging, with an enforced minimum width: beyond that, it stops shrinking and hides instead.
  • The left sidebar hides with ⌘B (Ctrl+B), which leaves more room for the rest.

The automatic behavior

The application adjusts the layout to the available width. When the window becomes too narrow to comfortably show the sidebar, the conversation and the panel, the sidebar folds away on its own and the conversation switches to a compact display. Widening the window, or ⌘B, brings it back.
