Les réglages, écran par écran

Cette page répond à une seule question : où se règle telle chose ? Elle donne la carte complète des cinq sections et des dix-sept onglets livrés avec Beaver, puis un index inverse qui part de ce que tu veux faire. Les cinq autres pages de cette section disent ce que chaque réglage fait vraiment.

Note C'est un sommaire, pas un manuel. Si tu sais déjà où aller, le tableau « Je cherche à régler… » plus bas te répond en une ligne.

Ouvrir les réglages

Les réglages sont l'un des quatre onglets principaux de Beaver, aux côtés de l'Agent, du Heartbeat et de la Personnalité. Dans la barre latérale, l'onglet porte le nom Paramètres.

Deux chemins pour y arriver :

  • cliquer sur l'onglet dans la barre latérale ;
  • le raccourci Cmd + , sur Mac, Ctrl + , ailleurs.

Comment l'écran est organisé

L'écran se lit en deux colonnes : à gauche la liste des onglets, groupés sous cinq en-têtes de section ; à droite le contenu de l'onglet sélectionné.

Trois comportements à connaître :

  • Les en-têtes de section ne sont pas cliquables. Ce n'est pas un oubli : ils sont volontairement privés de rôle de bouton et d'ordre de tabulation, pour que la navigation au clavier ne s'arrête pas sur une ligne qui n'ouvre rien.
  • La liste se parcourt aux flèches du clavier. Les flèches passent d'un onglet au suivant à travers toutes les sections confondues, dans l'ordre d'affichage.
  • L'onglet ouvert est mémorisé, avec le détail de ta position : fournisseur sélectionné, connecteur ouvert, modèle Ollama affiché, vue du catalogue de modèles distants. Revenir dans les réglages te ramène là où tu étais.

Les cinq sections, d'un coup d'œil

L'ordre des sections et des onglets n'est pas un accident d'affichage : il est déclaré une seule fois et tout l'écran en découle. Le regroupement suit un principe simple — les réglages sont groupés par objet configuré : les modèles, les connexions, le comportement de l'agent, les préférences, le cycle de vie de l'application.

Attention Deux réglages ne sont pas là où on les cherche. Accès fichiers — les dossiers ouverts à l'agent — est dans Agent › Avancé, pas dans Application. Et tout ce qui concerne le moteur Ollama — libération de la mémoire, processeur ou carte graphique, plusieurs modèles à la fois — est aussi dans Agent › Avancé, pas dans Modèles › Ollama, qui ne gère que les modèles eux-mêmes.

Ce qu'une extension peut changer dans cet écran

La liste des onglets n'est pas figée : une extension installée peut ajouter son propre onglet de réglages dans n'importe laquelle des cinq sections, et il apparaît dans la liste de gauche comme les autres. Elle peut aussi retirer, remplacer ou déplacer un onglet existant — avec deux exceptions verrouillées par le contrat des extensions lui-même.

Les deux éléments qu'aucune extension ne peut retirer
Élément protégéOpérations interdites
L'onglet principal ParamètresRetrait, remplacement
L'onglet de réglages ExtensionsRetrait, remplacement

Le raisonnement tient en une phrase : on ne peut pas installer une extension qui t'enlèverait le moyen de la désinstaller. Une tentative de modification sur ces deux éléments est rejetée. Une limite chiffrée existe par ailleurs : 128 occupants par emplacement au maximum.

Note Un onglet supplémentaire peut apparaître dans n'importe laquelle des cinq sections. Il vient de l'extension, pas de Beaver, et disparaît avec elle. Ce qu'une extension a le droit de faire est détaillé dans Centre d'extensions.
