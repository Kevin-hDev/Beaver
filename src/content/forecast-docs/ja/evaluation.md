# 評価と比較

評価は、計算時にモデルが見ていない履歴期間で性能を測ります。モデル名や大きさではなく、同じ時間窓の結果を比較します。

## ローリング時系列バックテスト

Forecast は履歴を複数の窓に分けます。各窓で過去だけを使用し、次の期間を予測するため、将来情報の混入を防ぎます。

履歴が短い場合は窓数や評価期間が減り、画面に警告が表示されます。

## ベースライン

| ベースライン | 仕組み |
| --- | --- |
| Naive | 最後の既知値を繰り返す |
| Seasonal Naive | 前回の同等な季節値を繰り返す |
| Drift | 観測された平均傾向を延長する |
| ETS | 可能な場合に水準、傾向、季節性をモデル化する |

## 指標

| 指標 | 読み方 |
| --- | --- |
| MASE | Naive に対する誤差。低いほど良い |
| sMAPE | 対称相対誤差。低いほど良い |
| MAE | 対象単位での平均絶対誤差 |
| カバレッジ | 実測値が区間内に入った割合 |
| 時間 | 観測された評価時間 |
| メモリ | 利用可能な場合の観測ピーク |

実測カバレッジを要求水準と比較してください。80% 区間が40%しか覆わない場合、校正は不十分です。

## 評価と比較

評価はバックテストを実行して詳細を表示します。比較は同質な結果だけを使い、精度、カバレッジ、速度、資源のバランスを示します。

一部だけ成功した実行を完全な検証として扱わないでください。

## 最良モデル

同じ窓を使い、結果が完全で、重要指標が優れ、信頼できるベースラインを上回り、ユーザー条件を満たす場合だけ最良と呼んでください。

比較可能なバックテストがない場合は、互換性または機能に基づく推奨と表現してください。

## モデルアンサンブル

複数モデルのバックテスト成功後、比較は2〜4モデルを MASE の逆数で重み付けして組み合わせられます。このアンサンブルは独立評価未実施と表示されます。
