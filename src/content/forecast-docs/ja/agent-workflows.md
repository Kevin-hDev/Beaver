# LLM エージェント

LLM は現在の会話から Forecast を操作します。データの準備や調査、品質監査、許可モデルの選択、計算、結果説明を行えます。

## 必須の流れ

新しいデータセットごとに、次の順で実行してください。

1. 対象、期間、予測範囲、要求された信頼水準を理解してください。
2. データを読み取りまたは作成し、出所を区別してください。
3. `forecast_data_audit` を呼び出してください。
4. ブロックするエラーを修正するか、ユーザーに説明してください。
5. 検証済みプロファイルで `forecast_models` を呼び出してください。
6. 手動では固定モデルを守り、正確な互換性を確認してください。
7. Auto では返された候補から1つだけ選んでください。
8. プロファイル、許可モデル、変更しない信頼水準で `forecast` を呼び出してください。
9. 必要なページと分析を `forecast_read` で読んでください。
10. 予測、不確実性、限界を説明してください。

データ、対象、頻度、範囲、信頼水準が変わった場合は監査をやり直してください。

## 手動モード

ユーザーの保存済み選択を変更しないでください。モデルがない、未準備、非対応の場合は、黙って別モデルを選ばず明確な操作を求めてください。

## Auto モード

返された候補から1つを選び、バックエンドの除外を回避しないでください。明示的なモデル指定も、Forecast が安全と確認した場合だけ使用してください。

選択 ID と許可された短い理由を `forecast` に渡してください。機能と資源だけに基づく選択を最良モデルと呼ばないでください。

## 評価と比較

ユーザーが最良モデルを求めた場合：

1. 対応モデルで `forecast_backtest` を実行してください。
2. 全体状態と個別失敗を確認してください。
3. `forecast_compare_models` で順位を読んでください。
4. Naive、Seasonal Naive、Drift、ETS と比較してください。
5. 誤差、カバレッジ、速度、メモリのバランスを説明してください。

部分バックテストを完全な結果として扱わず、信頼できるベースラインを超えないモデルを最良と呼ばないでください。

## 出所と説明

値がファイル、外部情報、計算、仮定のどれかを必ず示してください。重要なデータを黙って作らないでください。

既存の会話で説明、比較、再実行を行い、利用不能または信頼性の低い高度分析を正直に伝えてください。
