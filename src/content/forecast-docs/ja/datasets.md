# データセット

予測品質はデータから始まります。Forecast は履歴行、既知の将来情報、シナリオ用の仮定を分けて扱います。

## 最小構成

利用できるデータセットには、日付列、予測対象列、頻度、予測期間が必要です。任意の系列列で商品、地域、センサーなどを分け、共変量で追加情報を与えられます。

## 履歴領域

履歴行には日付と観測済みの対象値が必要です。時系列順で、十分な長さがあり、選択した頻度と一致していなければなりません。

Forecast は無効または順不同の日付、重複、欠損期間、空値や非数値、外れ値、履歴長、系列間の整合性を確認します。

構造上のエラーは実行を止めます。実行可能なリスクは警告として表示します。

## 将来領域

将来行は対象値を省略できます。カレンダー、予定価格、予算、キャンペーン、天気予報、予定能力など、既知の将来情報を入れられます。

不明な将来情報を事実として扱わないでください。

## 予測前の監査

新しいデータセットは必ず `forecast_data_audit` を通ります。監査はデータ、予測期間、頻度、要求された信頼水準を検証します。

監査に成功すると再利用可能なプロファイルが作成されます。LLM は全データを再送せず、そのプロファイルでモデル選択と予測を行います。

データ、対象、期間、頻度、信頼水準が変わった場合は監査をやり直してください。

## LLM が作成したデータ

LLM は CSV、表計算、JSON を読み、情報を調査して列を作成できます。ファイル、外部情報、計算値、シナリオ仮定を明確に区別する必要があります。

## プレビュー

データセクションには、行数、履歴点、将来行、系列、欠損期間、外れ値、マッピング、制限付きプレビューが表示されます。
