# 概要

Forecast は現在の会話に直接結び付いています。LLM はデータの準備や調査、計算、結果の説明を行います。チャットは常に操作の中心であり、2つの補助画面で分析を確認・検討できます。

## 基本の流れ

通常の流れは次のとおりです。

1. ユーザーがチャットで予測したい内容を伝える。
2. LLM が必要なデータを読み取り、作成または補完する。
3. Forecast がデータ品質を監査する。
4. 手動では選択モデルを固定し、Auto では安全な候補から選ぶ。
5. Forecast が予測を計算して保存する。
6. パネルが主要な結果をすぐに表示する。
7. ユーザーが会話を続けるか、Forecast ワークスペースを開く。

Forecast 専用の別チャットはありません。説明、比較、再実行は通常のメッセージで依頼してください。

## 役割の異なる画面

| 画面 | 役割 |
| --- | --- |
| チャット | データ準備、LLM の操作、説明の依頼 |
| Forecast パネル | グラフ、主要指標、警告の素早い確認 |
| Forecast ワークスペース | データ、グラフ、評価、シナリオ、ノート、レポートの詳しい確認 |

ワークスペースは会話を隠したり置き換えたりせず、専用ウィンドウで開きます。

## Forecast ワークスペース

ワークスペースは現在のセッションと分析に同期します。パネルで別の分析を選ぶと、開いているウィンドウも自動更新されます。

| セクション | 内容 |
| --- | --- |
| データ | 概要、マッピング、品質、プレビュー |
| 予測 | メイングラフ、不確実性、季節性、フィルター、表 |
| 評価 | 時系列バックテスト、ベースライン、区間の信頼性 |
| 比較 | 比較可能なモデル順位と任意のアンサンブル |
| シナリオ | 仮定の作成と編集 |
| ノート | コンテキスト、リスク、判断、注釈 |
| レポート | 詳細分析とエクスポート |

## 保存される分析

分析には、実際に使った列と設定、品質プロファイル、モデルと選択元、予測と区間、シナリオ、ノート、バックテスト、再現に必要な出所情報が保存されます。

## 重要な考え方

Forecast は構造化された推定を提供しますが、確実性を保証しません。データ品質、不確実性、ベースライン、利用可能な情報の限界と一緒に曲線を読んでください。
