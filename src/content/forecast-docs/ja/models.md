# モデル

モデルは予測を計算するエンジンです。Forecast はローカルとクラウドのモデル群を提供し、実行前に機能、準備状態、利用可能な資源を確認します。

## 利用可能なモデル群

| モデル群 | 提供元 | 主な用途 |
| --- | --- | --- |
| Chronos / Chronos-Bolt | Amazon | 高速なローカル確率予測 |
| TimesFM | Google | 汎用時系列予測 |
| Toto 2.0 | Datadog | メトリクスと監視系列 |
| MOIRAI 2.0 | Salesforce | 複数系列とコンテキスト変数 |
| FlowState | IBM | ローカル確率予測 |
| TabPFN-TS、TiRex、Kairos、Sundial | 各社 | 専門的または実験的なローカルモデル |
| TimeGPT | Nixtla | API キーを使うクラウド予測 |

対応する頻度、期間、共変量、複数系列、区間はアプリ内カタログを正として確認してください。

## 手動モード

手動ではユーザーがモデルを選び、Forecast がその選択を固定します。未準備またはデータや正確な信頼水準に非対応の場合、LLM は別の選択を求め、黙って置き換えません。

## Auto モード

Auto では、LLM は Forecast が絞り込んだ候補から1つだけ選びます。未準備、非対応、資源不足、未許可のクラウドモデルは除外されます。

ハードウェア情報は、この Forecast 選択中だけ LLM に渡されます。比較可能なバックテストがない限り、互換性または機能に基づく推奨と表現し、最良とは呼びません。

## インストールと準備

「準備」はモデルをダウンロードし、必要なランタイムを導入して、最初の予測前に実際の検証を行います。複数の準備はキューに入り、同じモデル群の変種はランタイムを共有できます。

| 状態 | 意味 |
| --- | --- |
| 未インストール | モデルファイルがない |
| 更新が必要 | ランタイムまたは検証の更新が必要 |
| 無効 | インストール不完全または検証失敗 |
| 準備完了 | モデルとランタイムを検証済み |
| プロバイダーが必要 | クラウド API キーがない |

ローカルモデルは準備完了時のみ選択できます。共有ランタイムは、他のモデルが必要としない場合だけ削除されます。

## クラウドモデル

クラウドモデルは必要なデータを設定済みプロバイダーへ送信します。Auto は許可、プロバイダー準備、データ方針のすべてを満たす場合だけ使用します。ローカルからクラウドへ黙って切り替えることはありません。
