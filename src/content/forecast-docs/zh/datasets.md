# 数据集

预测质量首先取决于数据。Forecast 会区分历史行、已知的未来信息和为场景创建的假设。

## 最小结构

可用数据集至少需要日期列、目标列、频率和预测范围。可选的序列列可区分产品、地区或传感器，协变量用于增加上下文。

## 历史区域

历史行包含日期和已观测目标值。数据必须按时间排序、长度足够，并与所选频率一致。

Forecast 会检查无效或乱序日期、重复项、缺失周期、空值或非数值、异常值、历史长度以及各序列的一致性。

结构性错误会阻止运行；非阻塞风险会显示为警告。

## 未来区域

未来行可以没有目标值，因为目标正是待预测内容。未来行可以包含日历、计划价格、预算、活动、天气预报或预计产能等已知信息。

不要把未知的未来信息描述成事实。

## 预测前审核

每个新数据集都必须先经过 `forecast_data_audit`。审核会验证数据、预测范围、频率和请求的置信水平。

审核通过后会创建可重复使用的数据档案。LLM 使用该档案选择模型和运行预测，无需重复发送全部数据。

数据、目标、范围、频率或置信水平发生变化时，请重新审核。

## LLM 创建的数据

LLM 可以读取 CSV、表格或 JSON、检索上下文并创建新列。它必须明确区分文件数据、网络数据、计算数据和场景假设。

## 工作区预览

数据区域会显示行数、历史点、未来行、序列、缺失周期、异常值、列映射和受限预览。
