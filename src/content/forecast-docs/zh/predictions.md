# 预测

预测根据历史、上下文变量和所选模型延伸一个或多个序列。结果包含中心估计，以及模型支持时的不确定性边界。

## 已保存结果

每次有效运行都会创建 `analysis_id`，用于关联面板、工作区、场景、笔记、评估和导出。

保存前，Forecast 会验证点数和序列数、未来日期及顺序、有限数值、分位数对齐和实际预测范围。不完整或不一致的输出不会保存为有效分析。

## 主图

主图会区分历史区域和预测区域。筛选器可以显示或隐藏序列、不确定性、场景、事件、比较、异常和质量信号。

你可以拖动平移、使用滚轮或触控板缩放、使用跳转条切换细节、折叠卡片并打开数据表。无法继续缩放时，图表不会阻止页面滚动。

## 辅助图表

工作区可显示不确定性扇形图、季节性比较图，以及回测后的可靠性图。多序列分析中，活动序列会在各图表间保持同步。

## 预测表

预测表默认折叠。打开后，会在限高滚动区域中显示日期、中心值和可用边界。

对于长分析，`forecast_read` 会分页返回有限数量的数据点，不会把整个序列放入 LLM 上下文。

## 实时更新

面板和工作区读取同一份分析。新预测、修改或当前分析切换会自动更新相关视图，无需关闭并重新打开窗口。

## 正确解读

请结合数据质量、不确定性、预测范围、异常、回测、基准和假设解读曲线。平滑曲线并不代表预测准确。
