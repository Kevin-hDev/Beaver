# 模型

模型是计算预测的引擎。Forecast 提供本地和云端模型系列，并在运行前检查能力、就绪状态和资源适配情况。

## 可用系列

| 系列 | 发布者 | 主要用途 |
| --- | --- | --- |
| Chronos / Chronos-Bolt | Amazon | 快速的本地概率预测 |
| TimesFM | Google | 通用时间序列预测 |
| Toto 2.0 | Datadog | 指标和监控序列 |
| MOIRAI 2.0 | Salesforce | 多序列和上下文变量 |
| FlowState | IBM | 本地概率预测 |
| TabPFN-TS、TiRex、Kairos、Sundial | 多家 | 专用或实验性本地模型 |
| TimeGPT | Nixtla | 通过 API 密钥使用云预测 |

应用内目录是频率、范围、协变量、多序列和区间支持情况的唯一依据。

## 手动模式

在手动模式中，由你选择模型，Forecast 会强制使用该模型。如果模型未准备好，或与数据和精确置信水平不兼容，LLM 会要求更换，而不会静默替换。

## 自动模式

在自动模式中，LLM 必须从 Forecast 已筛选的短名单中选择一个模型。未准备好、不兼容、资源需求过高或未获准使用的云模型会被排除。

硬件信息只会在本次 Forecast 选择期间提供给 LLM。没有可比回测时，Auto 只能说明兼容或基于能力的推荐，不能称为最佳模型。

## 安装和准备

“准备”会下载模型、安装运行环境，并在第一次预测之前完成真实验证。多个准备任务会进入队列，同一系列的多个变体可以共享运行环境。

| 状态 | 含义 |
| --- | --- |
| 未安装 | 模型文件不存在 |
| 需要更新 | 运行环境或验证需要刷新 |
| 无效 | 安装不完整或验证失败 |
| 已就绪 | 模型和运行环境已验证 |
| 需要提供商 | 缺少云服务 API 密钥 |

本地模型只有在已就绪时才能选择。卸载时，只有没有其他模型需要共享运行环境，才会删除该环境。

## 云模型

云模型会把必要数据发送给已配置的服务。只有在用户授权、服务已就绪且数据策略允许时，Auto 才会使用云模型。Forecast 不会静默从本地切换到云端。
