# 评估与比较

评估会在模型计算时未见过的历史周期上测量表现。它使用相同的时间窗口进行比较，而不是依赖模型名称或大小。

## 滚动时间回测

Forecast 将历史数据划分为多个窗口。每个窗口中，模型只使用过去的数据并预测下一段，从而避免未来信息泄漏。

历史较短时，窗口数或评估范围可能缩小，界面会显示警告。

## 基准模型

| 基准 | 原理 |
| --- | --- |
| Naive | 重复最后一个已知值 |
| Seasonal Naive | 重复前一个可比季节值 |
| Drift | 延伸观测到的平均趋势 |
| ETS | 在可行时建模水平、趋势和季节性 |

## 指标

| 指标 | 含义 |
| --- | --- |
| MASE | 相对 Naive 的误差，越低越好 |
| sMAPE | 对称相对误差，越低越好 |
| MAE | 以目标单位表示的平均绝对误差 |
| 覆盖率 | 实际值落入预测区间的比例 |
| 耗时 | 评估的实际运行时间 |
| 内存 | 可用时显示观测到的峰值 |

请把实际覆盖率与请求的理论水平比较。80% 区间如果只覆盖 40% 的观测值，说明校准不佳。

## 评估与比较区域

“评估”运行回测并显示详细结果。“比较”只使用同质结果，展示准确度、覆盖率、速度和资源之间的权衡。

不要把部分完成的运行描述为完整验证。

## 最佳模型

只有在模型使用相同窗口、结果完整、相关指标更好、超过可信基准并满足用户约束时，才可以称其为最佳模型。

没有可比回测时，只能说明兼容性或基于能力的推荐。

## 模型组合

多模型回测成功后，“比较”可以组合两到四个有效模型，并按 MASE 的倒数加权。该组合会标记为尚未独立评估。
