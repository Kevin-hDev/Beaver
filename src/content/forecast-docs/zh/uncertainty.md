# 不确定性

严谨的预测不只有一条曲线。Forecast 会把中心值与请求置信水平对应的不确定性区间结合起来。

## 中心值

中心值通常是中位数 `q50`。大约一半可能结果低于它，另一半高于它。

## 置信水平

连续模型接受 50% 到 99% 的整数百分点。用户未指定时，LLM 使用 80%。

部分模型只提供固定水平，目前为 60% 或 80%。Forecast 始终保留精确请求：Auto 只返回兼容候选，手动模式会报告不兼容，绝不会静默四舍五入。

## 边界与分位数

80% 中心区间通常使用 `q10`、`q50` 和 `q90`；90% 通常使用 `q05`、`q50` 和 `q95`。

## 不确定性扇形图

扇形图显示区间随预测范围扩大或收窄。边界越宽，精度越低。窄区间只有在校准良好时才有价值。

## 实际覆盖率

回测后，Forecast 会比较声明的水平与验证值的实际覆盖比例。历史数据太短时，该指标可能不稳定。

## 正确使用

使用不确定性比较周期风险、区分稳健趋势与脆弱路径、设置谨慎阈值、检查校准，并避免把场景假设当成确定结果。
