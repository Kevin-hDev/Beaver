# 概览

Forecast 与当前对话直接关联。LLM 可以准备或检索数据、运行计算并解释结果。聊天始终是控制中心，另外两个互补界面用于查看和深入分析。

## 主要流程

标准流程如下：

1. 用户在聊天中说明要预测的内容；
2. LLM 读取、创建或补充所需数据；
3. Forecast 审核数据质量；
4. 手动模式强制使用用户选择的模型，自动模式从安全候选中选择；
5. Forecast 计算并保存预测；
6. 侧边面板立即显示主要结果；
7. 用户继续对话，或打开 Forecast 工作区进一步分析。

Forecast 没有单独的聊天。需要解释、比较或重新运行时，直接在现有对话中发送消息即可。

## 互补界面

| 界面 | 用途 |
| --- | --- |
| 聊天 | 准备数据、指导 LLM、请求解释 |
| Forecast 面板 | 快速查看图表、关键指标和警告 |
| Forecast 工作区 | 深入查看数据、图表、评估、场景、笔记和报告 |

工作区在独立窗口中打开，不会隐藏或替换对话。

## Forecast 工作区

工作区始终跟随当前会话和分析。在面板中选择其他分析时，已打开的窗口会自动更新。

| 区域 | 内容 |
| --- | --- |
| 数据 | 数据摘要、映射、质量和预览 |
| 预测 | 主图、不确定性、季节性、筛选和数据表 |
| 评估 | 时间回测、基准和区间可靠性 |
| 比较 | 可比模型排名和可选的模型组合 |
| 场景 | 创建和编辑假设 |
| 笔记 | 上下文、风险、决策和注释 |
| 报告 | 详细分析和导出 |

## 已保存的分析

分析会保存实际使用的列和设置、数据质量档案、模型及选择来源、预测及区间、场景、笔记、回测和复现所需的来源信息。

## 核心原则

Forecast 提供结构化估计，而不是确定结果。阅读曲线时，请同时考虑数据质量、不确定性、基准和现有上下文的限制。
